# 示範模型

## Modern_House_Reference_02.skp

一棟兩層樓現代住宅，**專門為了測試這個網站而做的**：13 種材質、890 個面、
壓在草地上的鋪面、玻璃後方的襯底量體、二樓臥室的雪松格柵、20 邊形的樹冠。

**怎麼用：** 啟動網站後在首頁上傳它。轉檔約幾秒，完成後就能點選任何一面查資料。

### 已知的正確答案

模型的幾何是用 `generate_modern_house_02.rb` 寫死產生的，所以下面每個數字都可以
直接拿來核對。改了量測或合併規則之後，用這張表回歸比較。

| 看什麼 | 應該得到 |
|---|---|
| 全部面合計 | **5,699.62 m²**（890 個區塊、13 種材質） |
| 扣除重疊後 | **2,108.30 m²** —— 切到「扣除重疊」，合計掉 **63.0%** |
| 重疊面組成 | 359 組：量體貼合 243、薄板背面 45、幾何重複 71，共 3,591.32 m² |
| 格柵整片 | `Upper_Bedroom_Cedar_Screen` 的 20 支板條併成 3.41 × 2.02 m ＝ **6.88 m²**，而非逐面加總的 13.17 m² |
| 非建材排除 | 取消勾選「草地」（2,490.00 m²、43.7%）或「室內陰影」（484.07 m²、8.5%），合計會重算 |
| 多邊形輪廓 | 樹冠是 20 邊形、6.23 m²，選取面板會列出每一段邊長 |
| 表面類型 | 牆面 672、地坪／景觀 82、地板／樓板 68、天花 62、屋頂／斜面 6 |
| 室內表面 | 要先開右上角「水平剖面」才點得到室內地板／天花 |

`skpVersion` 是 22.0.316，SketchUp 2022 以上的 `SketchUpAPI.dll` 都讀得動。

### 這個模型「沒有」的東西

它整個是由軸向對齊的方盒組出來的，所以下面這幾條規則**在這個檔案上驗不到**，
不要以為是壞掉了：

- **開口扣除（`solidRatio`）** —— 窗洞是用壁柱、腰牆、楣樑幾塊實心量體圍出來的
  （見 `README_模型產生腳本.md`），不是在一片牆上挖洞，所以 890 個面的
  `solidRatio` 全部都是 1.0。
- **旋轉樓板、斜屋頂坡長、三角形量測** —— 模型裡沒有任何傾斜面，
  每個面的法線都沿著軸向。

這些規則是由 `converter/tests/` 用合成幾何涵蓋的
（`test_rotated_slab_reports_its_own_edges`、`test_sloped_roof_reports_rafter_length_not_plan`、
`test_opening_shows_up_as_solid_ratio` 等），改到那些邏輯時跑測試，不是看這個模型。
